Taking an order

Customer first, then items, then how it reaches them, then Checkout. The order appears on the board the moment you submit it.

ForStaffLine manager

ℹThe order is fixed

The item grid stays locked until a customer is chosen - it will say "Please select a customer first". This is on purpose: the customer decides the price list, the delivery fee and the branch.

1. Choose the customer

  1. 1

    Search by phone first

    Phone is the reliable way to find a repeat customer - names get typed differently every time. Switch to name search only if the phone finds nothing.

  2. 2

    If they are new, create them

    Create Customer takes the name, the type (Individual or Company) and the customer group. Take a second to get the phone right - it is how you will find them next time.

  3. 3

    Pick the delivery address

    Choose Shipping Address lists the addresses already saved for that customer, or lets you add one. The Territory on the address is what sets the delivery fee, so pick it properly.

⚠"Profile Mismatch"

If the customer's territory belongs to another branch, the app asks whether to keep your branch or switch to the territory's branch. Switch unless you have a reason not to - the branch that owns the territory is the one that can actually deliver there.

2. Add the items

  • •Tap a card to add one. The card shows In cart with the quantity already added, so you can see at a glance what is in the order.
  • •Bundles have their own tab. Opening a bundle lets you pick what goes inside it; Edit Bundle in the cart reopens that choice.
  • •Out of stock and "Stock limit reached. Only N available" mean the system has none left. You can still finish the order, but somebody has to actually find the goods.

3. Pickup or delivery

  • •Pickup (no delivery fee) - the customer collects from the branch. No slot, no courier, no delivery charge, and the order never needs a settlement.
  • •Delivery - you must pick a Delivery Time slot. The first available slot is marked Next.

⚠A slot that has passed is refused

The app will not let you submit onto a slot whose time is already gone. If the list looks short late in the day, that is why - pick the next real slot and tell the customer.

4. Check the cart

LineWhat it is
SubtotalThe goods, before delivery.
DeliveryThe delivery charged to the customer. Comes from the address territory.
Promo codeType a code and it shows Applied or Not eligible. "Not eligible" is the code's own rules - it is not a fault.
TotalWhat the customer pays.
Operational InfoDelivery Expense - what the delivery costs the branch. This is your cost, not the customer's price.

★Manager pricing

The Manager Pricing panel - price list, order purpose, zero shipping, a custom delivery amount, per-line discounts - is manager-tier only. Line managers do not get it either; a line manager who needs a different delivery charge on a live order requests it from the board instead.

5. Checkout

  1. 1

    Tap Checkout

    If anything in the cart is over the system's stock, a warning lists each line - requested N, available M. Proceed with order creates it anyway.

  2. 2

    Confirm

    "Order placed successfully!" means it is on the board, in the Received column, ready for the kitchen.

ℹPayment is not taken here

A delivery order is created unpaid on purpose. The money is recorded on the board when the order goes out or comes back settled - see the Order board page.

Parking an order

A half-built cart can be saved as a draft and picked up later - useful when a customer is still deciding and there is a queue behind them. There is a limit; if you hit "Draft limit reached", delete an old draft you no longer need.

When something goes wrong

▸The item grid is empty
Either no customer is selected, or the category filter is on something with nothing in it. Tap All first.
▸"Bundle contents could not be loaded"
Do not submit. Open Edit Bundle, reselect the items, and try again - submitting a bundle the app could not read produces an order nobody can fulfil.
▸"No delivery slots available"
Either the branch timetable is not set up, or every slot for today has passed. Check the branch is right; if it is, this is a setup issue for your manager.
▸I submitted the wrong order
Do not create a second one. Find it on the board: Edit Invoice changes what is in it, and a line manager can cancel it outright.
